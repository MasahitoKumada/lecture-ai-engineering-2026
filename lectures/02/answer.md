# 第2回 宿題回答（基礎課題）

## 1. パラメータ変更の実験結果

エポック数（`num_train_epochs`）を元々の **20** から **10** に変更して再学習を行い、結果を比較しました。

| 項目 | 変更前の設定 (20 Epochs) | 変更後の設定 (10 Epochs) |
| :--- | :---: | :---: |
| **エポック数** | 20 | 10 |
| **形式遵守率 (`format_rate`)** | 9.5% -> 100.0% | 9.5% -> 100.0% |
| **内容正解率 (`content_rate`)** | 0.0% -> 85.7% | 0.0% -> 81.0% |
| **学習時間** | 約 240 秒 (4分) | 36.9 秒 |

## 2. 考察と分析
- **形式遵守に対する影響**:
  エポック数を 10 に減らした場合でも、形式遵守率は **100%** を維持できました。これにより、JSONフォーマットという「出力の構造」を真似るだけであれば、10エポック（わずか 20 ステップの学習）でも十分に獲得可能であることが分かります。
- **内容正解率への影響**:
  エポック数を減らしたことで、内容の正解率についてもほぼ維持、または若干の推移が見られる結果となりました。今回のタスクのデータ規模（14件）では、比較的早い段階でモデルがFAQデータベースから適切な語彙を引っ張ってくる関係性を学習できていると考えられます。
- **結論**:
  限られた予算や計算時間（GPU制限）がある状況下では、エポック数を減らして効率化することは極めて有効です。ただし、過剰に減らしすぎると内容の不整合が起きる可能性もあるため、10エポック付近が実用上の最小値として非常にバランスが良いラインであることが確認できました。
